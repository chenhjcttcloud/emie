# 小觅：EMIE 工作与设计助手

## 首版范围

小觅在登录后的页面右下角提供统一对话入口，按钮显示“问问小觅”，切换业务页面时保留本次会话。助手按当前身份提供流程指导、本人待办查询、当前项目或任务说明，以及按需素材找图。退出或切换身份时清除旧上下文并中断旧请求。

入口按钮可用鼠标或触屏拖到页面其他位置，避免遮挡业务操作；当前浏览器会记住位置，窗口尺寸变化时自动限制在可见区域内。点击入口仍正常展开对话框，对话框会跟随入口位置并保持在屏幕内。

回答分为模型回答、系统业务指南和图档检索三种来源。模型未配置、额度不足或服务超时时，界面明确提示原因，保留基于已核对业务规则的指南和有权限的文字查询，不把本地指南标成模型推理结果。

首版由服务器按问题和页面背景执行有限的只读查询，再将必要事实交给模型组织回答；不开放任意工具执行。指南按代码维护版本，当前覆盖六类角色、项目总流程、子任务成果确认及积分核对入口，后续业务规则变更须同步维护。

## 业务依据与权限

- 业务规则按当前服务实现维护；项目总流程、子任务成果确认和设计需求分别说明，不直接导入过期流程文档。
- 身份从服务端登录会话取得。项目、任务、图档和素材读取沿用现有权限与数据范围，不接受模型指定角色或任意数据库查询。
- 图档检索要求管理员、产品企划或设计师角色，并具有“图档库查看”权限；查询共享图档，与图档库页面一致，不限本人上传。“为什么看不到图档”等权限问题由服务器根据实际权限直接说明。未匹配到关键词、或本轮未查询图库，都不表示没有权限；没有图库权限时不展示找图建议。
- 返回的项目、任务和图档卡片来自真实业务查询；模型生成文本不直接决定记录 ID、文件路径或访问权限。
- 首版通过页面入口、查看卡片与草稿协助操作，正式提交和审核仍经过原有业务流程。
- 对话只携带有界的最近消息、必要业务背景和当前明确选择的素材。模型密钥仅在后端保存，管理员设置读取不返回明文或密文。

## 素材找图

可通过文字描述、当前任务需求，或明确上传的参考素材发起找图。图库名称、IP、二级 IP 和文字标签用于匹配真实记录；对用户明确提交的素材，可按需提取检索信息。模型不可用时明确说明尚未理解素材画面，保留文字检索。

检索支持“KT猫”等中英文混合关键词，KT、HelloKitty、Hello Kitty 按同一 IP 别名匹配。返回卡片必须包含可读取的图库文件；历史未绑定条目 ID 的图库文件与图库原有访问规则一致。颜色、画风只有在现有名称、IP 或备注文字中有对应信息时才能命中，不对整座图库自动识别画面或保证样式符合。

支持选择文件、粘贴截图，以及将图片、AI 或 PDF 拖入小觅对话框或入口按钮。每次一个文件，单个不超过 15MB；拖入后可预览文件名或移除，只有点击发送才上传。拖入时显示接收提示；格式、大小、权限和当前模型能力校验与文件选择一致。

不会在每次对话中分析整座图库。已有图档、缩略图、预览、下载和任务关联数据继续保留。受保护的文件仍通过原有鉴权入口读取。

## 管理配置与调用限制

管理员通过“小觅设置”统一管理全系统模型。默认使用受保护的“服务器 Kimi（默认）”，保留部署中的接口、模型和密钥，不允许从页面删除。现有 `VISUAL_AI_*` 环境变量及同地址的历史加密密钥继续兼容；服务器配置不会成为自定义服务的密钥来源。

可添加最多 10 套独立模型配置。默认只需填写接口地址和对应 API Key，点击“获取模型列表”，再选择模型并保存；名称、服务商和兼容格式自动填写，其他选项放在高级设置中。获取列表不会保存密钥、切换当前配置或发起聊天请求。接口不提供模型列表时，可直接使用“手动填写模型”入口。

支持非流式 Chat Completions 兼容接口，提供 Kimi、DeepSeek、通义千问、OpenAI 及自定义兼容服务。模型列表读取复用公网 HTTPS 地址校验，不跟随重定向；每次读取须明确填写当前接口的密钥，不借用服务器或其他已保存配置的密钥。接口地址或 Key 改变、关闭设置、切换配置或身份后，旧请求会取消，旧列表不会用于新配置。原生 Claude Messages、Gemini 等不同协议需要额外适配或兼容网关。

“保存配置”与“切换使用”分别处理，可保存多套配置后选择当前使用项，也可保存后立即使用。选择、模型全局启停状态和加密密钥持久保存，重启后不丢失。删除当前自定义配置前明确提示，确认后回到服务器 Kimi。模型请求失败时只降级为系统指南/文字检索，不自动改用另一个计费账户。

密钥仅在获取模型列表或新增、更新配置时提交，列表、配置读取和聊天结果都不返回明文或密文。同一配置留空可保留原密钥；新配置或更改服务商/接口地址必须重新填写对应密钥。图片理解能力优先读取模型列表中的明确元数据；接口未提供时默认关闭，也可在高级设置中调整。不支持图片的配置使用文字找图，不调用文件解码或图片模型请求。

高级请求格式决定输出 token 参数。思考模式可选使用模型默认、关闭或开启，是否可用以具体型号为准；通用兼容/OpenAI 格式不发送其他厂商的专属思考字段。小觅不会仅凭模型名称前缀猜测能力。

配置接口为 `GET/POST /api/assistant/config`，要求管理员身份及对应配置查看/编辑权限。模型列表为 `POST /api/assistant/config/models`，仅有配置编辑权限的管理员可调用；限制请求、响应体、并发与等待时间。普通员工通过已鉴权的 `GET /api/assistant/model` 查看当前模型名称与能力，不取得管理配置或密钥；聊天为 `POST /api/assistant/chat`。

V97 仅新增模型配置和全局选择两张表，服务器加密配置须与数据库一起备份。旧识图批量分析仍保持退役。

一次提问最多一次模型调用，限制最近历史消息、响应长度、等待时间、并发和单个账号提问频率。业务查询在只读事务内完成后再调用外部模型，不跨外部请求持有数据库事务。对话在当前浏览器会话内保留，切换身份或退出后清除。

## 独立识图功能退出

- 移除“图档 AI 识图设置”和“分析一批已有图档”入口及旧配置、索引接口。
- 移除图档创建/修改后和打开任务详情时的自动模型识图。任务原有图档推荐只按需求文字与 IP 等元数据匹配。
- 已有数据库迁移、配置、历史特征缓存和任务关联不删除，不运行清库或回退迁移。
- 缩略图生成是原有文件预览能力，继续正常工作。助手明确提交素材时使用受限文件解析，避免重复读取大型原文件。

## 本地验证

修改后运行 Java 完整测试和 `./scripts/test-update.sh`。浏览器检查覆盖全局入口、切页保留、身份清理、明确的服务降级、真实卡片结构、管理员设置与旧独立识图入口消失。UI 模拟检查不替代真实模型连接验收；真实模型连接需服务商账户可用。

本项默认只在本地测试环境验证。提交、推送和生产部署需要用户在当前事项中明确授权。

## 兼容协议依据

- [Kimi 模型列表](https://platform.kimi.com/docs/api/list-models)：可用模型及明确的图片输入能力元数据。
- [DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)：模型名称与输入、输出模态。
- [百炼模型列表](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/list-models)：模型列表地址、结构及分页。

- [Kimi API 故障排查](https://www.kimi.ai/help/kimi-api/api-troubleshooting)：Kimi 输出限制使用 `max_completion_tokens`。
- [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)：DeepSeek 请求参数与可选思考模式。
- [百炼兼容 Chat API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)：模型、图片和思考模式的能力差异。
- [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：`max_completion_tokens` 及兼容参数。
