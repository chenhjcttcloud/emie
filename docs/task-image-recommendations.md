# 任务详情图档推荐

设计师“我的子任务”和项目内子任务详情会自动展示最多 8 个相关图档。推荐来自真实图档库，不为凑数量加入无关记录；同一任务最多关联 6 个图档。关联独立保存，不修改交付成果或原参考图记录。

## 匹配与缓存

- 使用任务名称、任务需求、项目需求、IP 与二级 IP，以及任务和项目参考图进行匹配。
- AI 提取主题、主体元素、风格、颜色和关键词；推荐理由仅来自实际分类、文字和视觉特征交集。
- 图档分析持久缓存，任务排序使用有容量和有效期限制的缓存。任务相关内容、图库内容或分析结果改变后，下次打开详情时重新匹配。
- 图档创建、修改成功后提交异步分析。已有图库可由管理员在“图档库 → AI 识图设置”中逐批分析，每批最多 48 个文件，不自动续批。
- 页面不轮询。分析中可先查看现有结果，稍后使用“更新推荐”或重新打开任务获取完成后的结果。
- AI 未配置、失败或文件不支持时保留 IP 和文字匹配，并明确显示当前状态，不将文字匹配标成 AI 识图。

## 配置

管理员可在图档库或“系统管理 → 系统配置”打开 AI 设置。服务通过后端调用支持视觉输入的 Chat Completions API。默认地址为 `https://api.moonshot.cn/v1`，模型为 `kimi-k2.6`。

容器可通过以下环境变量配置：

| 变量 | 用途 |
| --- | --- |
| `VISUAL_AI_ENABLED` | 是否允许调用 AI；编排模板默认关闭 |
| `VISUAL_AI_BASE_URL` | 公网 HTTPS 接口地址 |
| `VISUAL_AI_MODEL` | 支持图片输入的模型名称 |
| `VISUAL_AI_API_KEY` | 后端使用的 API Key |
| `VISUAL_AI_ENCRYPTION_KEY` | 至少 32 位随机值，用于加密管理页面保存的 API Key |

网页保存的配置优先于环境变量；密钥留空保留原值。读取接口仅返回是否配置密钥，不返回密钥或密文。备份数据库时须妥善保留加密配置；更换加密配置会使已有密钥无法解密。

当前图片输入最多 15MB，分析时缩放到最长边 1600 像素。PDF 与 PDF 兼容的 Adobe Illustrator `.ai` 文件分析前两页，不读取设计源文件的完整图层、路径或工艺信息。不兼容的格式会显示不可分析状态，仍可通过原有预览和下载确认。

图片解码及 PDF/AI 解析均在独立 Java 进程执行，不占用 Web 服务的解析堆内存。子进程堆上限 128MB、元空间上限 96MB，最长运行 45 秒；剩余内存不足 384MB 时暂缓分析。每页 JPEG 最多 2MB，最多两页，主进程只读取带尺寸及总量限制的编码结果。异常、资源超限或超时会终止该次分析并清理临时目录，保留名称/IP 匹配；子进程不继承数据库或模型密钥。

## 接口与权限

- `GET /api/projects/{projectId}/subtasks/{taskId}/image-recommendations?limit=8`：读取推荐与已有任务关联；同时检查任务所属项目、项目可见范围及图档库权限。
- `POST /api/projects/{projectId}/subtasks/{taskId}/image-recommendations/{libraryItemId}/associate`：幂等关联真实图档；仅任务负责人、项目企划或管理员可操作执行中的任务。
- `GET/POST /api/admin/visual-ai-config`：仅管理员读取或保存 AI 设置，并要求对应配置权限。
- `POST /api/admin/visual-ai-config/index-library`：管理员主动提交一批已有图档分析任务。

文件预览和下载沿用既有鉴权；AI 不接收用户提供的任意 URL 或路径。外部模型返回的内容只作为受限制的特征文本，不用于授予权限或执行指令。后台单并发、有界队列、超时和失败退避限制分析开销。

## 本地验收

```sh
node scripts/task-recommendations-check.cjs
scripts/mvnw-java21.sh test
./scripts/test-update.sh
node scripts/modal-e2e/task-recommendations.mjs
```

浏览器专项回归使用明确标记“UI 模拟”的独立响应，不把模拟推荐作为真实图库或真实业务验收。真实模型连接可用无业务内容的合成图片验证。

本功能默认只更新本地测试环境；生产发布需要另行明确指令。
