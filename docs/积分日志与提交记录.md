# 积分日志与提交记录

管理员入口：系统管理 → 运维与审计 → 积分日志。

统一展示子任务基础分和修改分、历史质量分、独立设计需求、素材采纳、PO、手动调整、异议更正、退单扣分。以基础流水和调整流水为准，PO专表是同一事件的业务记录，不再重复计入。可按人员账号、入账日期、来源、关键词和正负方向筛选；汇总与当前筛选范围一致。

新子任务每次提交由服务器记录时间，并冻结本轮规则、应发分和修改请求编号。企划确认时记录确认人、确认时间，积分关联该提交版本；确认和入账在同一事务内，数据库唯一约束防止重复入账。无积分修改仍记录提交与确认，但不生成积分流水。独立设计需求保留最新成果提交时间，沿用其自身发分流程。

子任务核对按提交日期和人员范围检查漏账、错分、错人、错规则、无积分轮出现流水及确认前入账。其他来源可通过统一流水追溯，不在子任务自动核对范围内。历史缺少追踪字段时显示未记录，不反推、不重算、不自动补发。

已有积分或退单调账记录的项目、子任务禁止物理删除，避免账务历史消失。发现异常后应先核实业务和原始流水，使用管理员调账或既有异议流程更正，保留原流水和更正原因。
